# SproutKit Game Data 🌱

Official game-data distribution repository for **SproutKit**, an unofficial Final Fantasy XIV companion app.

This repository hosts versioned SQLite databases and release manifests used to deliver over-the-air (OTA) game-data updates without requiring users to reinstall the Android application.

## What's included?

- Game items, crafting recipes and gathering information
- Fishing, hunting and vendor data
- Mounts, minions, achievements and other collection catalogues
- Item categories, materia bonuses and housing details

## Updates

Validated game-data packages are published through GitHub Releases.

SproutKit checks for compatible updates, verifies downloaded files and safely replaces its local game database while preserving personal collections, favourites and settings.
